# Web Programming Lab 2

Student: Ertuğrul Ünal  
Student Number: 240408016

This project uses one HTML file and two CSS files.

- `index.html` contains the six boxes.
- `styleA.css` shows the boxes vertically.
- `styleB.css` shows the boxes horizontally.

The main challenge was keeping the boxes in the correct places when the browser size changes.

To view Version B, change the stylesheet link in `index.html` from `styleA.css` to `styleB.css`.
